# Fixtures

Vector corpus and golden values (ADR-010 rev 2).

**CI gate:** a commit passes only if the committed vectors match what the
independent Python mirror computes (`python mirror/gen_slice_vector.py
--check`) *and* what the Rust implementation replays
(`crates/assay-core/tests/vectors_slice.rs`). A vector that changes silently
is a correctness regression nobody decided; regenerate only together with a
justified pipeline or grammar change, and say so in the commit message.

## slice/ — pipeline mechanics

`duo_slice.json` — inline mini-dataset, three loadouts with expected canonical
statblocks, and three exchanges with expected canonical outcomes. Generated by
the mirror; replayed by Rust.

Covers ADR-005 stages 1–8 (naked baseline, party-buff attribute timing —
stage 3 before 4 — gear rolls, flat move speed, the defensive chain, a
cap-raiser) and ADR-006 steps 1–9 (plain swing, **Sneak Attack from Hide**
where 0% scaling defeats the −30% power penalty, and Lethal Mark's
multiplicative PDR Mod combined with penetration, back attack and headshot).

Exchanges reference loadouts by name, so they ride on exactly the resolutions
the statblock cases lock — a resolution regression surfaces in both halves.

⚠ The curve shapes in this vector are **test-authored placeholders**, graded
`unverified`. They lock pipeline *mechanics*, not game truth. Golden fixtures
against the real Hotfix #123 dataset and the in-game character sheet are the
dataset arc's deliverable (ADR-010 rev 2 §5) — this file is deliberately not
that.

The vector-file shapes are local to this corpus; the real versioned dataset
format (`data/<build>/…`, ADR-004) is defined by `assay-data` when it lands.
